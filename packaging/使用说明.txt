Embedded Helper Windows x64 便携版

将 EmbeddedHelper.exe 放在可写目录，双击即可使用；无需安装 Python 或 .NET。
首次启动会自动在旁边的 data/runtime 准备内部组件，请稍候。
设置、工具和串口记录位于 data；升级替换主 EXE，迁移时一起携带 data。
不要手动更改 data/runtime 内部文件。组件损坏时，关闭程序后可移走当前组件目录让主EXE重新准备；不要删除整个 data。旧工程尚未迁移入口时须保留其旧组件目录。

四项导航：工程、查看变量、串口助手、设置与诊断。工程内包含工程概览、观察设置、远程配置。
先在工程中选择目标与已有 ELF，解析后勾选变量，配置连接方式、探针、采样率与本地RTT并保存。查看变量页读取工程保存值；缺项按钮返回对应设置。也可只观察本地RTT。
本机 JLink_x64.dll 与 readelf 路径在设置与诊断维护；硬件采集需要自行安装 J-Link/串口驱动，程序不会自动烧录。
远程功能先在设置中下载/导入 Debug_LAN，然后绑定 VS Code 入口并重启 VS Code。新入口变量 EMBEDDED_HELPER_ENTRY 指向外层 EXE，命令通过 --cli 进入当前版本；旧工程需预览并应用接入以迁移命令，旧 HOME 变量保持不变。
配置修改先预览后应用；本地入口保留，可移除远程接入并恢复 EIDE 上传方式。
变量与网页 RTT 手动二选一，返回变量前先在网页停止 RTT。

这是开发内测版。离线软件与界面自检不代表真实设备通过；设备、纯净Windows及30分钟实测由用户后续验收。
内部依赖许可见 data/runtime 当前版本目录的 THIRD-PARTY-NOTICES.txt。
